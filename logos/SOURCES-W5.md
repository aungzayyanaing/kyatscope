### Notes on edits made to official assets (all verified by rendering afterwards)

- **ABNB.svg / DASH.svg**: only the fill was resolved from a site CSS variable to the exact brand colour the logo renders as on the company's own homepage (#FF5A5F / #EB1700). Path data untouched.
- **LRCX.svg / SNPS.svg / ABNB.svg / DASH.svg**: inline SVG / sprite symbols extracted verbatim from the official homepage HTML into standalone SVG files.
