# KyatScope Logo Sources — Batch W2

Date verified: 2026-11-06. All logos taken from the company's own official website (homepage header logo, brand/media page, or the company's own CDN asset referenced by an official page). No aggregator, logo site, favicon API, Wikimedia, or third-party source was used. Every file was visually verified with the read tool; SVG files were rendered onto white (and, where white-only, onto the brand background) before approval.
